name: Brand name formatting
description: Required punctuation for two Doc of Detox treatment and retreat names.
---

Always write “Wolfe Non Surgical” and “5 Star” without hyphens in human-readable content.

**Why:** The user explicitly requires these names to remain unhyphenated as part of the project’s terminology.

**How to apply:** Use the unhyphenated forms in headings, body copy, metadata, labels, structured data, and source references. Keep technical URL slugs and asset filenames unchanged when altering them would break links or file loading.
